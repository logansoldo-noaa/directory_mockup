# Level 1b: Quality-Controlled (QCed) Data
**Definition:** Calibrated data from L1a that has been passed through automated quality control algorithms. Values are flagged for physical limits and closure tests.
**Hierarchy:** 
- For Broadband: `L1b_qced / [Station] / Broadband / [Format] / [Year]`
- For Others: `L1b_qced / [Station] / [Measurement] / [Year]`
